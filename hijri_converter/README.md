# محوّل التاريخ الهجري

تطبيق Flutter لتحويل التاريخ من هجري إلى ميلادي والعكس، ويعرض:

- **اليوم المصادف** للتاريخ (الأحد، الاثنين، …) والمدة بينه وبين اليوم.
- **عدد أيام الشهر الهجري** (29 أو 30)، ويرفض يوم 30 في شهر عدد أيامه 29.
- **الفروق بين طرق الحساب**: أم القرى، والحسابي الجدولي، والحسابي الفلكي، مع حكم واضح: "لا يوجد اختلاف" أو "يوجد اختلاف بمقدار يوم".

يعمل التطبيق دون إنترنت ودون أي مكتبات خارجية. جدول أم القرى مضمّن للسنوات 1300–1600هـ، وخارجها يُستخدم الحساب الجدولي.

## التشغيل

```bash
cd hijri_converter
flutter pub get
flutter run            # على هاتف أو محاكي متصل
flutter test           # اختبارات التحويل (أكثر من 3000 تاريخ مرجعي)
flutter build apk      # ملف APK لأندرويد
flutter build ios      # آيفون (يتطلب جهاز Mac و Xcode)
```

## بناء APK تلقائياً

عند كل رفع إلى GitHub يبني سير العمل `.github/workflows/hijri-apk.yml` ملف APK،
وتجده في تبويب **Actions** ← آخر تشغيل ← **Artifacts** ← `hijri-converter-apk`.

## هيكل الكود

- `lib/calendar.dart`: منطق التحويل بين التقاويم.
- `lib/umalqura_data.dart`: جدول أطوال أشهر أم القرى.
- `lib/main.dart`: واجهة التطبيق (عربية، من اليمين لليسار، فاتحة وداكنة).
